## v0.0.8

### Highlights
- **Read PDFs:** the agent can open PDF files: metadata, search, extracted text, and pages rendered as images (with zoomed-in crops). Text works with any model; page images need a vision-capable one.
- **Slimmy:** your agent's avatar - an optional animated figure in the session header acts out what the model is doing (reading the prompt, thinking, writing a tool call, waiting on a subagent). Turn it on with "Show Slimmy" in the settings; it holds still when the OS asks for reduced motion.

### Other changes
- Updated Avalonia to 12.1.5 and SkiaSharp to 4.154.0.
